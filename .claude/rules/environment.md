# Среда проекта — грабли, купленные потерянным временем

> Вынесено из `CLAUDE.md`, `HANDOFF.md` и `docs/LESSONS.md`. Каждый пункт стоил
> сессии или её части. Это факты о среде, а не советы по стилю.

## ⛔ Первое действие любой сессии, которая тронет данные

```bash
netstat -ano | findstr ":5199 :5200 :4173 :4199"
```

⚠️ Смотреть на строки со словом **LISTENING**. `TIME_WAIT` остаётся от уже закрытых
соединений и читается как «сервер жив», хотя сервера нет.

⚠️ **Порядок уборки в конце работы: сначала увести ВКЛАДКУ, потом гасить сервер,
потом удалять служебную строку** (урок У-69). Вкладка, загруженная до остановки
сервера, живёт дальше и продолжает опрашивать базу каждые восемь секунд: однажды
она завела удалённую строку `vuoksa2026-test` заново через пять минут после уборки.
Увести — `location.replace('about:blank')` через `javascript_tool`.

Найденное — остановить. Брошенный сервер прошлой сессии держит вкладку со старой копией
листа; правка файла вызывает её горячую перезагрузку, и она отправляет устаревшее
состояние в боевую строку (урок У-07). Записи в `.claude/launch.json`, указывающие в
папки прошлых сессий, удалять.

Затем снимок:

```
GET https://…/rest/v1/trips?id=eq.vuoksa2026&select=data,updated_at,author
```

Пустой `author` при непустых данных — тревога. Сдвиг `updated_at` — норма, заказчик
правит лист живьём.

## Локальный запуск

```
http://localhost:5199/?u=Maks&k=<ключ Макса>&sandbox=1
```

⚠️ **`preview_start` открывает голый адрес.** `navigate` его не уводит. Работает только
`location.replace('http://localhost:5199/?u=Maks&k=<ключ>&sandbox=1')` через
`javascript_tool` сразу после открытия.

Голый адрес без `?u=` даёт права владельца — поведение первой версии, портировано
намеренно. Защита: `isSandbox()` в `app/src/lib/supabase.ts` считает песочницей **любой**
`localhost` / `127.0.0.1`, а не только `?sandbox=1`. Снимать нельзя.

⛔ **Ключей команды здесь больше нет, и вписывать их сюда нельзя.** Репозиторий
`github.com/starobormaksim-stack/vuoksa-2026` **публичный**: всё, что попало в этот
файл, читает кто угодно. Ключ — это пропуск в боевой лист; однажды они уже утекли
именно так и были заменены (запись в `HANDOFF.md`, «ключи заменены»).

Действующий ключ брать из последнего снимка `backups/prod-*.json` (папка в гит
не ходит — `.gitignore`), поле `people[].key`:

```bash
node -e "const d=require('./backups/prod-2026-08-06T2246.json')['0'].data; for(const p of d.people) console.log(p.slug, p.key, p.perm)"
```

⚠️ **08.08.2026: ключи в этом файле были устаревшие на двое суток**, и ссылка
из задания сессии боевым листом не признавалась — `rpc/trip_read` отвечал
`401 {"code":"42501","message":"ключ не подходит"}`. Живая проба со ключом
из снимка открыла лист с первого раза. Ключ, который «перестал работать», —
это почти всегда старый ключ, а не поломка сервера.

## ⛔ Вкладка не рисует кадров

Это главная особенность среды, и она врёт молча.

* **Скриншоты** и `read_page` могут не сниматься вовсе либо показывать несобранный кадр.
  Вердикт по виду они не выносят.
* **Эмуляция 390 px** частично считает раскладку по реальному окну. `resize_window`
  меняет окно, но не `innerWidth` страницы.
* `IntersectionObserver` **спит** → активный раздел считается `getBoundingClientRect()`,
  наблюдатель оставлен вторым будильником.
* **Доставка `scroll`-событий заморожена**: программный `scrollLeft` двигает узел,
  но слушатели не зовутся. Проверять логику синтетическим
  `el.dispatchEvent(new Event('scroll'))`.
* `scrollTo({behavior:'smooth'})` **не едет вовсе**. Проверять подменой на `'instant'`.
* `<img loading="lazy">` **не грузится**.
* **Exit-анимации Radix заморожены**: закрытое меню висит в разметке с
  `data-state="closed"` — судить по атрибуту, а не по наличию узла.
* `await` вокруг `requestAnimationFrame` **не резолвится никогда**. Синхронный рефлоу:
  `void document.body.offsetWidth`.
* Элемент с недоигранным входом Motion навсегда стоит на смещении; `getAnimations()`
  при этом **пуст** (Motion гонит инлайн-стиль по кадрам, не через WAAPI). Геометрию
  покоя читать как `rect − new DOMMatrixReadOnly(cs.transform).f`.
* **CSS-переходы тоже не доигрывают.** Элемент с `transition-colors` после смены темы
  навсегда остаётся на СТАРТОВОМ цвете, и `getAnimations()` возвращает 0 — прибор молчит,
  а `getComputedStyle().color` врёт. Замер контраста в этой среде получался 1,56 : 1
  там, где на самом деле 5,79 : 1 (урок У-55). Перед замером цвета снимать переходы:
  `document.querySelectorAll('*').forEach(e => e.style.transition = 'none')`
  плюс `void document.body.offsetWidth`.
* Результат `setState` в том же вызове не прочитать — React флашит асинхронно.
  Нажатие и чтение разметки — два разных вызова инструмента.

## Чем мерить

| Вопрос | Инструмент |
|---|---|
| где стоит и какого размера | `getBoundingClientRect()` |
| перекрыто ли, доходит ли нажатие | `elementFromPoint()` |
| читается ли | вычисленный контраст WCAG по `getComputedStyle` |
| есть ли горизонтальный скролл | `documentElement.scrollWidth` vs `clientWidth` |
| глазами | **Playwright** — единственный способ |

Radix и vaul кликать тройкой: `pointerdown` + `pointerup` + `click`. Одиночный `click`
часть органов не открывает.

⚠️ **Деградировавший канал инструментов возвращает правдоподобную выдумку.** Пустой или
подозрительно гладкий вывод пробы — перепроверить одиночным вызовом до того, как он
попадёт в отчёт.

⚠️ Когда замер расходится с глазом заказчика больше одного раза — печатать **сырые
данные** (координаты, цвета пикселей, вычисленные стили), а не посчитанный итог.
И проверять подозреваемого **снятием** прямо в браузере, а не рассуждением о нём.

## Публикация и свежесть

Cloudflare Pages собирает сам при `git push`: корневая папка `app`, команда
`npm run build`, каталог `dist`, ветка `main`, версия Node из `app/.nvmrc` (22).

Свежесть боевого сверять **по содержимому**: искать в отданных файлах строку,
появившуюся именно в этой правке. Хеш коммита совпадает и тогда, когда край
Cloudflare ещё отдаёт старое.

⚠️ **Имя файла сборки на боевом ДРУГОЕ, чем локально, и это норма.** Cloudflare
собирает проект у себя, поэтому `assets/index-*.js` получает свой хеш: 06.08.2026
локально лежал `index-D44RcdyS.js`, а боевой отдавал `index-BC1rtdqn.js`. Искать
локальное имя на боевом бессмысленно — оно вернёт `text/html` (SPA-заглушку)
и будет прочитано как «не выложилось». Верный путь: скачать боевой `index.html`
с обходом кеша, вытащить из него имя скрипта и уже в НЁМ искать новую строку.

⚠️ **Тело запроса с русскими буквами слать файлом.** `curl -d '{"n":"Уборка"}'`
в этой оболочке ломает кодировку, и PostgREST отвечает
`PGRST102 Empty or invalid json`. Работает только `--data-binary @файл`.

⚠️ **Прямой SELECT и DELETE по таблице `trips` для anon отдают пустой ответ,
а не ошибку.** `docs/rls-apply-e.sql` снёс ВСЕ политики: всё идёт через
`security definer`-функции. `DELETE` при этом честно возвращает 200 и `[]` —
это выглядит как «удалили», хотя не удалено ничего. Функции `trip_drop`
в базе нет, поэтому убрать строку из среды нельзя вовсе; максимум — обнулить
её через `rpc/trip_write`, убрав из документа ключи команды: тогда она пропадёт
из «Моих поездок» и перестанет хранить данные.

⚠️ Сразу после выкладки браузер может закешировать SPA-заглушку вместо файла кода
(признак: скрипт отдаёт `text/html`). Лечится жёсткой перезагрузкой, кода не касается.

⚠️ `no-cache` для `/sw.js` из `_headers` Cloudflare не применяет — отдаёт свой
`max-age=14400`. На самообновление не влияет: приложение просит `sw.js?v=<хеш коммита>`.

## Чужие кабинеты

Заказчик в них **не ходит** (урок У-45). Supabase, Google Cloud, Cloudflare — делать
самому: Playwright, MCP-серверы, коннекторы. Что физически невозможно из среды —
сказать одним предложением, а не списком домашних заданий.

Известные ограничения на сегодня: MCP-серверы `figma` и `supabase` требуют авторизации,
которую в неинтерактивной сессии пройти нельзя — тогда путь через Playwright или REST
с anon-ключом.
