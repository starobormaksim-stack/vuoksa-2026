## Задачи этой сессии

### 1. Переезд на Cloudflare Pages и домен `pine-to-pine.com`

Домен зарегистрирован заказчиком в Cloudflare, панель:
`https://dash.cloudflare.com/b1aaa7a020801b699cfbf3d3e896996c/domains/registrations/pine-to-pine.com`

**Как это делать (заказчик так попросил дословно).** В его аккаунты самому не заходить,
пароли и коды не вводить ни при каких обстоятельствах. Вместо этого **вести по шагам**:
одно действие — одно сообщение, куда зайти и что нажать, и дожидаться результата,
прежде чем давать следующий шаг. Экраны описывать словами («слева в меню Workers & Pages»,
«кнопка Create application»), а не терминами из документации. Порядок шагов определяешь сам.

Разумный порядок (проверь, не изменился ли интерфейс Cloudflare):

1. **Проект Pages из репозитория** `starobormaksim-stack/vuoksa-2026`.
   Сборка: команда `npm --prefix app run build`, каталог вывода `app/dist`.
   Тогда собранные файлы перестанут лежать в корне репозитория, и `publish-v2.mjs`
   останется нужен только для офлайн-файла — заметное упрощение.
   **Пока переезд не завершён, GitHub Pages не отключать.**
2. **Домен на проект**: `pine-to-pine.com` и `www`. Cloudflare сам заведёт записи —
   домен зарегистрирован у него же. Сертификат выпускается сам.
3. **Красивые адреса** `pine-to-pine.com/<поездка>/<имя>` — со стороны кода уже готовы:
   `app/public/_redirects` отдаёт любой путь в `index.html`, а `readUrlUser`
   в `app/src/lib/perm.ts` понимает и путь, и прежний `?u=…&k=…`. Осталось проверить
   на живом домене и перевыпустить людям короткие ссылки (первый заход всё равно
   должен быть по полной ссылке с ключом — ключ запоминается в браузере).

### 2. Регистрация владельца через Supabase Auth

Заказчик просит не выдумывать своё, а взять готовое:

* владелец — единственный, кто регистрируется (Supabase Auth, magic link по почте);
* остальные заходят **по личным ссылкам**, как сейчас, права те же;
* готовые экраны входа брать из shadcn-блоков (`npx shadcn@latest add login-01` и соседние)
  или Aceternity — не рисовать с нуля;
* **модель прав не менять**: владелец / редактор / участник, как описано в `README.md`
  и реализовано в `app/src/lib/perm.ts`. Сейчас разграничение «джентльменское» (anon-ключ
  лежит в коде); с Supabase Auth появляется возможность включить RLS по `auth.uid()` —
  это и есть смысл задачи.

### 3. Хвосты, которые стоит закрыть заодно

* **Google-геокодер отвечает `REQUEST_DENIED`.** Обратное геокодирование работает через
  запасной бесплатный Nominatim (`app/src/lib/geocode.ts`), но Google был бы точнее.
  Причина, скорее всего, — не включён **Geocoding API** в проекте `pine-to-pine`
  Google Cloud Console (шаг включения API прервался требованием двухэтапной проверки).
  Провести заказчика: Google Cloud Console → поиск `Geocoding API` → Enable.
  Ключ карт уже ограничен по referrer и работает — Maps JavaScript API принимается.
* **`google.maps.Marker` объявлен устаревшим** (предупреждение в консоли). Работать будет
  ещё долго, но при случае перевести на `AdvancedMarkerElement`.
* **Сборка одним куском 1,19 МБ** (464 КБ в gzip). Разрезать по разделам не пробовали.
  Если заказчик пожалуется на долгое открытие с телефона — начинать отсюда.
* **Сортировка «Кто уже собрался» по проценту** переставляет строки на лету, без анимации:
  отметил вещь — человек перепрыгнул. Если режет глаз, порядок можно замораживать на сессию.
* **Меток участников четыре** (`toneOf` в `app/src/lib/people.ts`): у пятого человека
  форма и насыщенность повторятся. Пока в команде четверо — не мешает.
* **Долгий тап по заголовку раздела** (переименование) проверен только логикой, не на живом
  телефоне: на iOS возможен системный «callout». Кнопка «⋯» рядом делает то же самое.
* **Промежуточные тосты в мастере «Новая вещь»**: `TextSheet` и `NumberSheet` показывают
  свои обычные тосты ещё до того, как вещь заведена. Если мешает — добавить им флаг «без тоста».

## Чего ломать нельзя

* **Боевые данные** — одна строка `trips` с `id='vuoksa2026'`. Проверки — ТОЛЬКО с `?sandbox=1`,
  после проверок строку `vuoksa2026-test` удалять.
  **Локальный адрес открывать сразу с `?sandbox=1`**: голый адрес без `?u=` даёт права
  владельца и пишет в боевую строку. Внимание: `preview_start` открывает вкладку на голом
  адресе — сразу переходить на адрес с песочницей.
  Агентам, которые смотрят раздел вживую, писать полный адрес с `sandbox=1` прямо в задании.
* Модель прав. Слияние правок по позициям (`mergeInto`, метки `ua`, `S.del`).
* Русский язык и типографика, без `alert()`/`confirm()`, эмодзи как иконки не используются,
  Миша — не «Мишка». Ничего из данных поездки не выбрасывать.
* Правила интерфейса из UX-проекта: список показывает — шторка редактирует (в строке нет
  полей ввода), никаких знаков `×`, `÷`, `=`, цели касания ≥ 44 × 44, строка списка ≥ 64 px,
  горизонтального скролла нет при 390 px.
* Бренд — ровно четыре цвета, все прочие оттенки только их смеси. Название — только Chewy.
  Люди различаются не цветом, а насыщенностью янтаря и формой метки (`lib/people.ts`).

## Как проверять и публиковать

```bash
node app/scripts/check-sums.mjs      # 330 км, 21 385 / 26 005 / 47 390 / 11 848 ₽, 2 канистры
npm --prefix app run build
npx oxlint app/src
```

Локальный запуск — конфиг `flops-app-dev` (порт 5199) или `flops-app-dev-alt` (5200)
из `.claude/launch.json`; открывать `http://localhost:5199/?u=Maks&k=zdzua343&sandbox=1`.

Публикация:

```bash
npm --prefix app run build && npm --prefix app run build:offline && node publish-v2.mjs
git add -A && git commit -m "что поменялось" && git push
gh api repos/starobormaksim-stack/vuoksa-2026/pages/builds/latest --jq .status   # built
```

**Про проверки в браузере этой среды.** Вкладка не рисует кадры. Отсюда следует, что
НЕ работают и молча дают ложный результат: скриншоты, `IntersectionObserver`,
события `scroll`, `scrollIntoView({behavior:'smooth'})`, отрисовка Google Maps (`.gm-style`).
Проверять надо иначе: геометрию — через `getBoundingClientRect()`, прокрутку — через
`behavior:'auto'`, обработчики прокрутки — рассылая `window.dispatchEvent(new Event('scroll'))`,
готовность Google — наличием конструкторов `google.maps.Map`. Клики по компонентам Radix
срабатывают через раз.
