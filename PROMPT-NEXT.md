## ⛔ Первое действие — порты, потом жив ли СВОЙ сервер

```bash
netstat -ano | findstr ":5199 :5200 :4173 :4199"
```

Смотреть строки со словом **LISTENING**. Найденное — остановить.

Лист больше НЕ живёт в Supabase. Свой сервер — `server/`, выложен на Vercel:

```bash
curl -s -X POST https://pine-to-pine-api.vercel.app/rest/v1/rpc/trip_read \
  -H "Content-Type: application/json" --data-binary @body.json
```

где `body.json` — `{"p_id":"vuoksa2026","p_key":"<ключ Макса из backups/prod-2026-08-09-p31-start.json>"}`.
⚠️ Тело слать **файлом**: `curl -d '…'` в этой оболочке ломает кодировку.

* **200 и мегабайт данных** — сервер жив. ПЕРВЫМ ДЕЛОМ снять снимок в `backups/`.
* **не 200** — сказать заказчику одним предложением и работать локально
  (снимок в `localStorage['flops.doc']`, см. ниже).

Проба локально, ничего не трогая: заглушить сеть в Playwright
(`route('**/rest/v1/**' → 402)`), положить `data` из снимка в
`localStorage['flops.doc']` через `addInitScript`, открыть
`http://localhost:5199/?u=Maks&k=<ключ>&sandbox=1`. Работает, проверено трижды.

⚠️ **Ширину окна ставить ДО загрузки страницы.** `matchMedia('change')` в этой
среде не приходит: `useIsDesktop()` остаётся с тем значением, что было при

## Про свой сервер — что надо знать, прежде чем его трогать

* Код — `server/api/rest.js`, одна функция на все пути; `server/vercel.json`
  переписывает `/rest/v1/:path*` на неё. Выкладка: `cd server && vercel deploy --prod --yes`.
* Хранилище — Vercel Blob `pine-to-pine` (`store_CEew3tDRVXb7XjTY`), привязано
  к проекту `pine-to-pine-api`, команда `sport-location`.
* ⛔ **`DOC_SECRET` менять нельзя** — этим ключом зашифрован документ. Сменишь —
  лист станет нечитаем, и вернуть его можно будет только из снимка.
* ⛔ **`QUIET_TICKS` в `lib/sync.ts` не уменьшать без счёта в ВЫЗОВАХ функции**
  (У-176): 20 секунд — это 518 тысяч в месяц вчетвером при бесплатном миллионе.
* ⛔ **`SB.realtime = false`** — у Vercel сокета нет. Ставить `true` бессмысленно:
  консоль наполнится ошибками, а присутствие всё равно не поедет.

## Что осталось незакрытым

1. **Полоска «кто сейчас в листе» пуста.** Присутствие ехало по сокету Realtime,
   а у своего сервера его нет. Восстановить можно поверх уже идущего опроса метки:
   `trip_pings` может отдавать заодно тех, кого видели за последние полминуты, —
   лишних запросов не добавится. Заказчику про это сказано.
2. **`owner_email` у боевой строки пуст** — в снимке его не было. Вход по почте
   в эту поездку не работает; личная ссылка работает. Проставить — одной записью
   через сервер, но сначала спросить заказчика, та ли это почта.
3. **Условная запись не мгновенна** (У-176). Если заказчик увидит потерянную
   правку при одновременном редактировании — вот причина, и лечится она
   настоящей сделкой, то есть другим хранилищем.
4. **Картинки внутри документа.** Обложка 602 КБ, лица 429 КБ строками base64 —
   это 1 МБ из 1,1. Место им в файловом хранилище, в документе ссылка. Пока это
   не сделано, каждое настоящее изменение листа стоит мегабайта всем четверым.
   Правка формы хранения: сначала архитектор (постулат 4), потом код. **Это
   и есть следующая крупная работа.**
5. **Supabase.** Проект `oagonfdnlgqkoosvgaly` больше не используется. Когда
   лимит снимут, его можно просто закрыть — данные оттуда уже перенесены.

Партнёров на карте **не начинать**.
