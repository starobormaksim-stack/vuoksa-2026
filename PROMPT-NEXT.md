## ⛔ Первое, что надо усвоить: как не убить боевые данные

04.08.2026 боевую строку многократно затирали вкладки, открытые по «голому» адресу.
Правила, без исключений:

* **Снять страховочный снимок ДО начала работы** и сохранить в песочницу сессии:
  `GET https://oagonfdnlgqkoosvgaly.supabase.co/rest/v1/trips?id=eq.vuoksa2026&select=data,updated_at,author`
  (заголовки `apikey` и `Authorization: Bearer` — anon-ключ лежит в `app/src/lib/supabase.ts`).
* **`preview_start` СНАЧАЛА открывает голый адрес.** Проверено 04.08.2026: и с параметром
  `url`, и с именем конфига из `.claude/launch.json` вкладка сперва встаёт на голый адрес,
  и `navigate` со строкой запроса её оттуда НЕ уводит — помогает только
  `location.replace(...)` через выполнение сценария на странице. Порядок такой:
  `preview_start({url:'https://example.com'})`, потом поднять сервер, потом сразу же
  `javascript_tool` → `location.replace('http://localhost:5199/?u=Maks&k=zdzua343&sandbox=1')`,
  потом **проверить адрес вкладки** и **проверить, что боевая строка не сдвинулась**.
* **Перед правкой файлов проверить, не работает ли чужой сервер разработки**
  (`netstat -ano | grep :5199`, а также `Get-CimInstance Win32_Process -Filter "Name='node.exe'"` —
  брошенные серверы прошлых сессий слушают и другие порты).
* После проверок удалять строку песочницы `vuoksa2026-test`.
* Признак беды: у строки `vuoksa2026` пустой `author` при непустых данных.
* Агентам в задании писать полный адрес с `sandbox=1` и запрещать поднимать серверы вовсе.

### 1. Проверить глазами то, что сделано вслепую — САМОЕ ГЛАВНОЕ

Вкладка в этой среде не рисует кадров, поэтому весь прошлый этап проверялся геометрией
и чтением кода. Заказчику надо посмотреть и сказать, а сессии — починить, если не так:

* **Шапка во встроенном браузере Телеграма на iOS.** Это третий заход; если «сквозное
  отверстие» осталось — значит причина не только в `sticky`, и надо смотреть, что делает
  Телеграм со своей полоской. В коде уже есть: `fixed` вместо `sticky` + распорка,
  непрозрачная полоса над шапкой, один `<meta name="theme-color">`, меняющийся с темой.
* **Свежая версия доезжает?** Открыть сайт на телефоне, ничего не нажимая, и убедиться,
  что версия свежая. Если карта на телефоне всё ещё OpenStreetMap при свежей версии —
  ВОТ ТОГДА разбираться с ключом Google (в консоли на телефоне искать `gm_authFailure`).
* **Метки Google, тап по метке, перетаскивание** на живом адресе.

### 2. Защита боевого листа — нужно решение заказчика, потом работа

## Чего ломать нельзя

* **Боевые данные** — см. раздел в начале файла. Это главное правило проекта.
* Модель прав. Слияние правок по позициям (`mergeInto`, метки `ua`, `S.del`) и **страховку
  `fillMissingKeys`** в нём: она не даёт устаревшей вкладке терять поля.
* `trip.dist.auto` и формулы в `app/src/lib/calc.ts`. Контрольные суммы обязаны сходиться.
* Русский язык и типографика, без `alert()`/`confirm()`, эмодзи как иконки не используются,
  Миша — не «Мишка». Ничего из данных поездки не выбрасывать.
* Правила интерфейса: список показывает — шторка редактирует (в строке нет полей ввода),
  никаких знаков `×`, `÷`, `=`, цели касания ≥ 44 × 44, строка списка ≥ 64 px,
  горизонтального скролла нет при 390 px.
* Бренд — ровно четыре цвета: графит `#262513`, хвоя `#2B391A`, крем `#F9F3D4`,
  янтарь `#BC6C25`. Все прочие оттенки — только их смеси. Название — только шрифтом Chewy.
* `base` в `app/vite.config.ts`: на Cloudflare `'/'`, везде ещё `'./'`.
* **`__BUILD__`** в `vite.config.ts` и версия в адресе работника (`sw.js?v=…`): без них
  сайт снова перестанет обновляться сам.

## Как проверять и публиковать

```bash
node app/scripts/check-sums.mjs      # 330 км, 21 385 / 26 005 / 47 390 / 11 848 ₽, 2 канистры
npm --prefix app run build
npx oxlint app/src
```

⚠️ `npx tsc` в корне не работает — TypeScript установлен в `app/node_modules`:

```bash
cd app && ./node_modules/.bin/tsc --noEmit -p tsconfig.app.json
```

Локальный запуск — конфиг `flops-app-dev` (порт 5199) из `.claude/launch.json`, и сразу же
увести вкладку на `http://localhost:5199/?u=Maks&k=zdzua343&sandbox=1` (см. раздел про данные).

Публикация: **`git push` — и Cloudflare соберёт сам.** Офлайн-файл и раскладка для GitHub
Pages нужны, пока старый адрес живой:

```bash
npm --prefix app run build && npm --prefix app run build:offline && node publish-v2.mjs
git add -A && git commit -m "что поменялось" && git push
```

Проверить, что боевой адрес обновился:

```bash
curl -s https://pine-to-pine.com/ | grep -oE '/assets/index-[A-Za-z0-9_-]+\.js'
```

**Про проверки в браузере этой среды.** Вкладка не рисует кадры. Не работают и молча дают
ложный результат: скриншоты, `IntersectionObserver`, события `scroll`,
`scrollIntoView({behavior:'smooth'})`, отрисовка тайлов карты, анимации появления и ухода
у шторок (узел в разметке есть, но остаётся сдвинутым за экран — это не поломка).
Проверять надо иначе: геометрию — через `getBoundingClientRect()`, перекрытие — через
`document.elementFromPoint()`, прокрутку — через `behavior:'auto'`, готовность Google —
наличием `.gm-style`, метки `AdvancedMarkerElement` — поиском их узлов в разметке.
Клики по компонентам Radix обычным `.click()` срабатывают через раз; надёжнее послать
`pointerdown` + `pointerup` + `click`.
