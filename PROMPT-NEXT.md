## ⛔ Первое действие сессии — проверить, что боевой ЖИВ

```bash
curl -s -o /dev/null -w "%{http_code} %{content_type}\n" \
  -H "Origin: https://pine-to-pine.com" \
  -H "Accept-Encoding: gzip, deflate, br, zstd" \
  "https://pine-to-pine.com/assets/index-<хеш>.js"
```

Имя файла брать из свежего `index.html`. **`text/html` = сайт мёртв** (У-127).
Вердикт «работает» выносить только загрузкой страницы Playwright'ом
с подсчётом `document.getElementById('root').children.length` — должно быть 1.
`curl` без `Origin` в этом вопросе врёт.

## ⛔ Чего трогать нельзя (свежее)

* **Три вещи под картой не возвращать**: строку «Без места на карте…», строку
  `road.note` («По воде и пешком линия прямая») и кнопку «Я здесь». Точки без
  координат показывает чип «Точки без транспорта» в полосе веток.
* **Поиск отбирает сам** (`pickHits` в `SearchCommand.tsx`), у диалога стоит
  `shouldFilter={false}`. Вернёшь фильтр cmdk — вернётся «куча ненужного» (У-132).
  До первой буквы списка нет вовсе — это тоже прямая просьба.
* **`visibleBlockId` меряет по СЕРЕДИНЕ видимой части** (У-131). Верх экрана —
  место, откуда текст уходит.
* **Свёрнутая группа расчёта обязана показывать свой итог** (`Line.sum`), а группы
  с целями переходов («Топливо и техника», «Аренда и парковка», «Итоги») открыты
  по умолчанию: свёрнутая группа не отрисована, и `jumpToItem` придёт в пустоту.
* **Значок места на обложке вынут из потока** (`PIN_BTN`, сдвиг 14 px) — иначе
  название снова уедет на 20 px правее даты. Текст лежит выше кнопки (`z-10`).
* **Плитки сумм — две колонки на любой ширине**: колонка обложки 416 px,
  четыре плитки ломают «43 509 ₽» пополам.
* Прежние запреты в силе: карточка точки не открывается при постановке (У-128);
  имя от геокодера только вместо `NEW_POINT` и пустого; `t.tone` и `t.color`
  в `sig` обеих карт (У-129); `bg-accent-fill` только с `text-on-accent`,
  подсветка выбора — `bg-accent-soft` (У-130); `Transport.color` старше `t.tone`,
  проверяется `normHex`; строка ветки — `<div>` с двумя кнопками;
  `--bottom-nav-h` из `navpref.ts`; `toneOf(t, idx)` везде; свой `digits = dg(value)`;
  ветки строками; `MAP_TONES` только для карты; обёртка `<Command>` в
  `ui/command.tsx`; `lastIndexOf` в `lib/offline.ts`; `S.tileLabels` — позиционный
  массив; `S.secTitles` — объекты по ключам первой версии.
