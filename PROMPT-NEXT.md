## Ключевые решения (уже приняты, не переспрашивать)

* Сервис называется **FLOPS**. Название пишется ТОЛЬКО логотипом (`src/logo-light.svg` /
  `src/logo-dark.svg`), никогда текстом. Песочные элементы эмблемы заливаются цветом фона
  (CSS `[fill="#E4D0A5"]{fill:var(--bg)}`) — логотип «прозрачен» к заднику.
* Брендбук: светлая тема — фон ровно `#E4D0A5`, тёмная — ровно `#2B391B`,
  акценты `#BC6C25` / `#A74612` / `#161C10`. Шрифт **Manrope везде** (вшит base64,
  `src/fonts-manrope.css`), Georgia убрана.
* Решён **переход на React** (Vite + Tailwind + shadcn/ui и Aceternity как источники компонентов +
  Motion + Lucide + Leaflet/OSM, маршруты — публичный OSRM без ключа). Каркас в `app/`,
  данные уже мигрированы в `app/src/data/seed-v2.json` со сверкой сумм (`app/scripts/migrate.mjs`).
  Старая версия (`src/` + `build.js`) остаётся боевой до паритета. Ничего из v1 не удалять.
* Многоагентная работа (Agent/Workflow: продукт-архитектор, UX/UI-дизайнер через `frontend-design`,
  тестировщик) разрешена заказчиком на весь этап — переспрашивать не нужно.

## Чего ломать нельзя

* Боевые данные — строка `trips` с `id='vuoksa2026'`. Проверки — ТОЛЬКО с `?sandbox=1`
  (документ `vuoksa2026-test`), после проверок строку песочницы удалять.
* Офлайн на айфоне: приложение на экране «Домой» + скачиваемый самодостаточный файл; всё сетевое
  вырезается при сохранении (`SAVE_STRIP`). В офлайн-файле кнопки #bSave и #bMe остаются
  (в онлайне они скрыты стилем `#hdrTrim` — он вычищается при сохранении файла).
* Права по личным ссылкам; слияние правок по позициям (`mergeInto`, метки `ua`, `S.del`).
* Русский язык и типографика, без `alert()`/`confirm()`, эмодзи как иконки не используются,
  Миша — не «Мишка». Ничего из данных поездки не выбрасывать.
* Мобильный приоритет 390×844, интерактив ≥ 44×44, горизонтального скролла нет.

## Как проверять и публиковать

* Локально: сервер из `.claude/launch.json` (порт 4173), адрес
  `http://localhost:4173/?u=Maks&k=zdzua343&sandbox=1`. Смотреть 390 и 1280/1920, обе темы,
  консоль без ошибок. Проверять обе сборки: `index.html` и офлайн `Вуокса-2026.html`.
* Сборка v1: `node build.js`. Публикация: `git add -A && git commit && git push`,
  проверка: `gh api repos/starobormaksim-stack/vuoksa-2026/pages/builds/latest --jq .status` → `built`.
* В этой среде вкладка браузера может не рисовать кадры: `requestAnimationFrame`, плавная прокрутка
  и события `scroll` не срабатывают — проверять вызовом функций напрямую; внешний вид — скриншотами,
  если среда позволяет, иначе вычисленными стилями плюс геометрией элементов.
