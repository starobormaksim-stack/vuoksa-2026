**Как мерить, пока база мертва** (проверено в 34-й порции, работает лучше прежнего):

1. `node -e "…"` кладёт `data` из снимка в `app/public/__probe-doc.json`;
2. в браузере: `localStorage.setItem('flops.doc', <этот JSON>)`, затем
   `location.replace('http://localhost:5199/?u=Maks&k=<ключ>&sandbox=1')`;
3. приложение считает это своей местной копией и рисует лист целиком, **оставаясь
   обычным приложением** — в отличие от `__probe-doc.js`, который включает режим
   офлайн-копии, где карты нет вовсе.

⚠️ **Вкладка среды считается СКРЫТОЙ** (`document.hidden === true`), и опрос
сервера в ней спит — тик в `Sync.start()` первым делом проверяет `document.hidden`.
Замер синхронизации без этого показывает ноль запросов и читается как «сломано».
Снимать так:

```js
Object.defineProperty(document, 'hidden', { get: () => false, configurable: true })
Object.defineProperty(document, 'visibilityState', { get: () => 'visible', configurable: true })
```

⛔ Оба следа (`__probe-doc.json`, запись в `localStorage`) убрать до сборки.
