## Как проверять, ничего не сломав

* **Боевые данные — одна строка `trips` с `id='vuoksa2026'`.** Перед экспериментами снимай копию:
  `GET /rest/v1/trips?id=eq.vuoksa2026&select=data,updated_at,author` с anon-ключом из `src/online.js`.
* Для проверок добавляй к адресу **`?sandbox=1`** — это отдельный документ `vuoksa2026-test`,
  боевой не трогается. После проверок строку песочницы удаляй.
* Локальный просмотр: простой статический сервер на `node` из папки проекта, порт 4173,
  затем `?u=Maks&k=zdzua343&sandbox=1`. Проверять на ширине 390 px, смотреть консоль на ошибки.
* Realtime уже включён на сервере (таблица `trip_pings` в публикации `supabase_realtime`).
  Присутствие требует в `phx_join` конфига `presence:{key:…, enabled:true}` — без `enabled`
  сервер не присылает `presence_state`.

## Модель прав (согласована с заказчиком, менять нельзя без него)

* **Владелец** — всё. Только он скачивает офлайн-копию, возвращает её в онлайн и видит ссылки экипажа.
* **Редактор** — всё, кроме того, что касается владельца: его карточку, его права и его отметки
  не трогает. Файл не скачивает. Остальных участников может править, удалять и отмечать за них.
* **Участник** — свой список: свои отметки, свои позиции, своё описание и фотография.
  Может добавлять позиции и **ставить задачи другим**, но не отмечать за них и не трогать общие
  параметры (логистика, маршрут, меню, экипаж).

Точки входа в коде: `permOf` / `myPerm` / `isEditor` / `isChief` / `canEditItem` / `canMark` /
`canEditPerson` / `canSetPerm` / `canSaveFile` / `permRights` в `src/app.template.html`.
В онлайне `permOf` и `canSaveFile` подменяются в `src/online.js` — права даёт только ключ из ссылки.

## Ограничения, которые нельзя нарушать

Один HTML-файл на версию, весь CSS и JS внутри, ванильный ES5, без npm, фреймворков и внешних
загрузок (модуль синхронизации и всё, что связано с сетью, вырезается при сохранении файла —
список селекторов в `SAVE_STRIP`). Мобильный приоритет, проектирование под 390 × 844,
интерактивные элементы не меньше 44 × 44 px, горизонтального скролла нет. Всё на русском,
с русской типографикой, без `alert()` и `confirm()`, эмодзи как иконки не используются.
Имена участников: **Миша**, не «Мишка». Ничего из данных поездки не выбрасывать.
