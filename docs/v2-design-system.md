# FLOPS · дизайн-система v2

Для React-версии (`app/`): Vite + Tailwind v4 + shadcn/ui + Aceternity (источники компонентов и блоков) +
Motion + Lucide. Всё адаптируется под фирменный стиль FLOPS, компоненты не берутся «как есть».
Утверждено заказчиком: имя FLOPS (начертание — только из логотипа, текстом не набирается),
Manrope везде, светлая тема — пергамент, тёмная — хвоя, акценты из тройки `#BC6C25 / #A74612 / #161C10`.

внутренние песочные (светлая) / хвойные (тёмная) элементы эмблемы заливаются `var(--bg)` —
логотип «прозрачен» к заднику (правило `[fill="#…"] {fill:var(--bg)}`).

Тема — **личная настройка браузера** (localStorage), не поле общего документа (в v1 это поле `S.theme`
синхронизировалось на всех — в v2 так не делать).

## 2. Типографика

**Manrope — единственный шрифт**, включая заголовки и суммы. Вшит base64 (`src/fonts-manrope.css`,
переменный вес 200–800, кириллица + латиница). Название сервиса шрифтом не набирается — только логотип.

| Роль | Размер/высота | Вес |
|---|---|---|
| Экранный заголовок (h1 обложки) | 32–36 / 1.1 | 750 |
| Заголовок раздела (h2) | 24 / 1.2 | 700 |
| Заголовок карточки (h3) | 20 / 1.25 | 650 |
| Имя/строка-акцент (h4) | 16 / 1.3 | 600 |
| Текст | 15.5 / 1.45 | 400–500 |
| Вторичный, подписи | 12–14 / 1.35 | 500 |
| Надзаголовок (uppercase) | 11–12, letter-spacing .12em | 600 |
| Суммы и цифры | 20–32 | 700, `font-variant-numeric: tabular-nums` |

Русская типографика: «ёлочки», длинное тире, неразрывный пробел перед единицами (`44 л`, `21 385 ₽`).

## 3. Сетка, радиусы, тени, плотность

- Сетка 8px; внутренние отступы карточек 16/20, между секциями 24–32.
- Радиусы: карточки 16, кнопки и поля 10–12, чипы 8, круглые аватарки 8 (квадрат со скруглением).
- Тени (светлая): `sm` 0 1 2 rgba(43,57,27,.06); `md` + 0 10 30 rgba(43,57,27,.09); `lg` 0 18 44 rgba(43,57,27,.13). В тёмной — чёрные с большей непрозрачностью.
- Мобайл 390×844 — приоритет; интерактив ≥ 44×44; горизонтального скролла нет.
- Десктоп: контейнер 1120, экипаж 4 карточки в ряд, обложка — квадрат слева + панель справа.
  Десктоп не «растянутый мобильный»: двухколоночные компоновки, воздух.

## 4. Навигация и шапка

- **Число разделов динамическое** (пользователи добавляют свои) — меню рендерится из данных.
- Мобайл: нижняя панель; при > 6 пунктов — последний пункт «Ещё» со шторкой.
- Десктоп: **прилипающее верхнее меню** (утверждено вместо левой панели): слева логотип,
  далее пункты-табы с подчёркиванием-индикатором (Motion layoutId), переполнение — в выпадающий «Ещё».
- Шапка: только присутствие (стопка аватарок), поиск, тема, «⋯». Логотип: мобайл — в шапке 44px
  по левому краю контента; десктоп — в верхнем меню, без дублей.
- Основа: shadcn `navigation-menu` + `sheet`; индикатор — Motion.

## 5. Компоненты (основа → адаптация)

| Наш компонент | Основа shadcn/Aceternity | Адаптация |
|---|---|---|
| Кнопки primary/secondary/ghost/danger | `button` | primary — accent с тенью; radius 12 |
| Поля, числовые поля | `input` | подчёркнутый пунктир редактируемого — фирменная черта, сохранить |
| Выпадающие (единицы, виды техники, валюта) | `select` / `combobox` | пункт «своё…» открывает ввод; введённое попадает в список |
| Календарь дат поездки | `calendar` + `popover` | диапазон, русская локаль |
| Шторки (мобайл) | `drawer` (vaul) | скругление 16 сверху, ручка |
| Аккордеоны групп | `accordion` | ленивая отрисовка содержимого (принцип lazyBody из v1) |
| День погоды | `accordion` в строке | тап — день раскрывается шире, соседи сжимаются (Motion layout) |
| Тосты с «Отменить» | `sonner` | 6 секунд, кнопка отмены |
| Чипы статусов сборов (5 состояний) | `badge` | цвета: 0 muted / 1 фиолет `#8A6FA8` / 2 bark / 3 pine / 4 water |
| Карточка экипажа | `card` + свои оверлеи | роль и «это я» — бейджи на фото слева; «сейчас здесь» — зелёная точка+подпись в текстовой части справа |
| Обложка «Поездки» | Aceternity hero-блоки (image + gradient overlay) | квадрат на десктопе, контент внизу, редактирование по месту |
| Карта | Leaflet + OSM, маркеры-точки | только онлайн; в офлайн-сборке секция скрыта |
| Пустые состояния | своё | иконка Lucide + 1 фраза + действие |
| Скелетоны | `skeleton` | тон `--zebra` |

## 6. Движение (Motion)

- Кривая `cubic-bezier(.2,.8,.2,1)`; 120мс (отклик) / 250мс (раскрытия) / 400мс (переходы экрана).
- Переход раздела: fade+сдвиг 14px один раз, не на каждую перерисовку.
- Раскрытие дня погоды и групп — `layout`-анимации; появление строк — stagger 30мс.
- Индикатор меню — shared layout (`layoutId`).
- `prefers-reduced-motion` — всё отключается.
