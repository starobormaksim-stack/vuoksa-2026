# DEFINITION-OF-DONE · Pine-to-Pine

Что считается «сделано». Короткий ответ: **без живого замера — не сделано.**

Причина, по которой этот файл существует: за одну сессию несколько раз работа
объявлялась готовой по типам и сборке, а живьём была сломана (урок У-10).
Поиск сносил всё приложение. Обложка уезжала за экран. Панель съедала фотографию
целиком. Заказчик открывал сломанное после слова «готово» — и это дороже любой правки.

## Четыре ступени. Слово «готово» произносится только после четвёртой

### Ступень 1 — ДОПУСК (это не готовность)

```bash
node app/scripts/check-sums.mjs      # 330 км · 21 385 / 26 005 / 47 390 / 11 848 ₽ · 2 канистры
npx oxlint app/src
cd app && ./node_modules/.bin/tsc --noEmit -p tsconfig.app.json
npm --prefix app run build
npm --prefix app run build:offline
```

Всё пять — с выводом в отчёт. `npx tsc` в корне **не работает**, только так, как написано.
Контрольные суммы гоняются после каждой правки расчётов, а не в конце.

⛔ Пройденная ступень 1 даёт право **начать проверку**. Она не даёт права сказать
«работает», «починил», «готово». Формулировка на этой ступени ровно одна:
«собирается, типы чистые — иду мерить».

### Ступень 2 — ЗАМЕР (здесь появляются числа)

Меряется то, что менялось, **и соседи в том же контейнере**.

| Что проверяем | Чем меряем | Что кладём в отчёт |
|---|---|---|
| Геометрия, не уехало ли | `getBoundingClientRect()` | числа left/right/top/bottom/width |
| Перекрытия, доходит ли нажатие | `elementFromPoint()` в центре органа | какой узел вернулся |
| Читаемость | вычисленный контраст WCAG | отношение, порог 4,5 : 1 |
| Цель касания | `elementFromPoint` на ±21 px от центра | отзывается / нет |
| Горизонтальный скролл страницы | `documentElement.scrollWidth` vs `clientWidth` | равны или нет |

Обязательный минимум по ширинам и темам:

* **390 × 844** и **1280** — обе, всегда, для любой правки раскладки (урок У-11);
* **светлая и тёмная** — обе;
* сцена **в двух состояниях** — исходном и прокрученном (урок У-20).

⚠️ Наличие узла в разметке ничего не доказывает. Ненулевой размер ничего не доказывает.
Доказывает только `elementFromPoint` и число.

### Ступень 3 — ЖИВОЙ ПРОГОН (как человек, а не как код)

Сценарий проходится нажатиями, а не изменением состояния напрямую.
Радиксовые органы кликаются тройкой `pointerdown` + `pointerup` + `click`.
Для взгляда глазами — поднимается Playwright; браузер среды кадров не рисует и врёт.

Прогоняется: путь, который менялся, плюс **соседний путь того же раздела** — тот,
который правка могла задеть.

### Ступень 4 — ПРИЁМКА ТЕСТИРОВЩИКОМ

Работа исполнителя **не считается принятой**, пока тестировщик не показал измерения.
Тестировщик видит дифф и критерии, но не ход рассуждений исполнителя, и имеет право
вернуть работу. Отчёт субагента без вывода команд и чисел — не отчёт (уроки У-50, У-48).

## Что обязано быть в отчёте перед словом «готово»

1. **Изменённые файлы** — списком, с путями.
2. **Выполненные проверки — с выводом.** Не «прогнал tsc», а сам вывод.
3. **Замеры** — числа по таблице ступени 2, на обеих ширинах, в обеих темах.
4. **Соседи** — что стояло рядом и какие у них числа стали (урок У-11).
5. **Оставшиеся риски** — честно, включая «этого среда проверить не даёт».
6. **Что рекомендуется дальше.**
7. **Промпт следующей сессии — текстом в чат**, а не только файлом.

## Чего нельзя писать в отчёте

| Нельзя | Потому что | Как надо |
|---|---|---|
| «Работает» | не проверено живьём | «Замерено на 390: …» |
| «Должно работать» | это предположение | «Проверить не смог: <чем именно>» |
| «Скорее всего, починилось» | догадка вместо замера | замер или честное «не знаю» |
| «Заказчику надо зайти в …» | он туда не ходит (урок У-45) | сделать самому или одно предложение о невозможном |
| «Прогнал проверки» без вывода | вывод и есть доказательство | сам вывод |
| «Скриншот подтверждает» | вкладка не рисует кадров | числа замера |

«Не знаю» — законный ответ, и он дешевле выдумки. Незакрытое остаётся незакрытым вслух,
а не закрывается правдоподобной версией.
